# 0005 – BSD-3-Clause license

- **Status:** Accepted
- **Date:** 2026-10-26

## Context

docshelf is an open-source project meant to be used and extended by others. Django and Wagtail
are BSD-3-Clause.

## Decision

BSD-3-Clause.

## Alternatives

- **MIT:** equally permissive, but differs from the ecosystem it plugs into.
- **GPL / AGPL:** protects against closed forks, but discourages adoption by agencies and
  companies, which are the main contributors in the Wagtail ecosystem.

## Consequences

Contributions are accepted under the same license; no CLA.
